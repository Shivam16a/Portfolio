## 🎨 <span style="color: #38bdf8;">Key Features & UI/UX Highlights</span>

- **🔮 Glassmorphism Aesthetic:** Crafted with custom CSS backdrop filters, glowing multi-color gradients, and smooth dark-mode interface (`#0f172a` theme).
- **📱 Responsive Mobile Navigation:** Custom-engineered mobile dropdown menu layout with smooth collapse behavior and precise breakpoints.
- **⚡ Dynamic Content Management:** Add, manage, and sync technical skills, development tools, and projects dynamically via Google Sheets/Apps Script.
- **📊 Active Section Highlighting:** Real-time scroll detection tracking current active sections (`About`, `Skills`, `Projects`, `Contact`).
- **🚀 Lightning-Fast Hosting:** Deployed and optimized seamlessly on Netlify.

## 💻 <span style="color: #00f5ff;">Getting Started Locally</span>

<p>Follow these simple steps to set up and run the portfolio on your local machine:</p>

1. **<span style="color: #ff00cc;">Clone the repository:</span>**

```bash
   git clone https://github.com/Shivam16a/Portfolio.git
   cd Portfolio/Shivam
```

2. **<span style="color: #ff00cc;">Install frontend dependencies:</span>**
```bash
npm install
```


3. **<span style="color: #ff00cc;">Run the development server:</span>**
```bash
npm run dev
```
